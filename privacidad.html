Política de privacidad

Última actualización: 1 de noviembre de 2026.

TC Tracker es una aplicación personal de uso privado para registrar entrenamientos de CrossFit. Su único usuario es también su propietario. Esta política describe qué datos de tu cuenta de Google utiliza y qué hace con ellos.

Permiso de Google que solicita

  • Gmail, solo lectura (gmail.readonly): la aplicación busca los correos de aviso de entrenamiento enviados por el entrenador (plataforma TrueCoach) de los últimos días y lee su contenido para extraer el texto del entrenamiento de cada día. No envía, modifica, etiqueta, archiva ni elimina ningún mensaje; el permiso no lo permite.

Para qué se usan los datos

Únicamente para cargar la programación semanal en la propia aplicación del propietario. No se usan para ningún otro fin, ni para publicidad ni para entrenar modelos de inteligencia artificial.

Almacenamiento y compartición

  • De cada correo reconocido como aviso de entrenamiento solo se guarda el texto del entrenamiento y su fecha. El resto del correo no se conserva. Los correos que no corresponden a avisos de entrenamiento se descartan sin guardar nada.
  • La aplicación guarda en el servidor privado del propietario un token de acceso, para consultar la cuenta sin pedir la contraseña cada vez, y el resultado de la última importación (correcta o con error).
  • No se venden, ceden ni comparten datos con ningún tercero.
  • Ninguna persona, salvo el propietario, accede a estos datos.
  • El uso que la aplicación hace de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso y borrar los datos

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, el token deja de funcionar y la aplicación pierde todo acceso a tu cuenta. Para eliminar además el token y los entrenamientos guardados, basta con borrarlos del servidor del propietario.
